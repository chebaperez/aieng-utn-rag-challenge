Construí un microservicio HTTP de caja negra (POST /solve) capaz de resolver consultas cuantitativas sobre reportes financieros 10-K (TAT-QA) combinando tablas contables, notas aclaratorias, cómputo determinista y abstención responsable.

1. Lectura Tabular 2D

Interpretar matrices financieras con encabezados jerárquicos, unidades implícitas y orden temporal variable.

2. Evidencia Híbrida

El 59.3% de los casos (89/150) exige cruzar la tabla con párrafos y notas al pie (table-text).

3. Cálculo Determinista

Prohibido calcular "de memoria" en el LLM: toda fórmula debe ejecutarse vía herramientas trazables.

4. Abstención (ABSTAIN)

Detectar evidencia faltante o amputada vale 0.0 pts; inventar una cifra cuesta -1.0 pt.
